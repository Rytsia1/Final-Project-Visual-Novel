**Konvensi naskah**
- Teks biasa = narasi / monolog batin Devano (text box narasi)
- `NAMA:` = baris dialog
- `*(…)*` setelah baris Mandarin = subtitle untuk pemain (pinyin + terjemahan)
- `(…)` di dalam cabang = narasi pendek khusus cabang itu
- **▸ PILIHAN** = titik pilihan; semua opsi terbuka (tanpa syarat stat)
- **⤷ GABUNG** = semua cabang kembali ke alur utama
- `flag:` = penanda untuk callback di hari berikutnya (tidak mengubah stat)
